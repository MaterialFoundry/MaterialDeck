# Material Deck
Material Deck is a premium Foundry VTT module that allows you to control certain Foundry functions using an Elgato Stream Deck. A Stream Deck is a device that has physical buttons with displays behind them. Material Deck uses this to, for example, control playlists, execute macros, display and control the combat tracker.

See the [documentation](https://materialfoundry.github.io/MaterialDeck) for more info.
